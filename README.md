# Bestin frontend

React + TypeScript UI for Bestin: book upload, text/voice chat, and a lip-synced 2D avatar.

```bash
cp .env.example .env
npm install
npm run dev
```

`VITE_API_URL` should point at the FastAPI server (default `http://localhost:8000`). See the root [README](../README.md) for the full system.
